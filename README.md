# Newshop Project

این فایل README نشان می‌دهد که من به فایل‌های پروژه شما دسترسی کامل دارم.

## ساختار پروژه

من می‌توانم ببینم که پروژه شما شامل موارد زیر است:

- **backend**: پوشه مربوط به بک‌اند پروژه
- **frontend**: پوشه مربوط به فرانت‌اند پروژه
- **.vscode**: تنظیمات مربوط به VS Code

## دستورات Git

برای ارسال تغییرات:
```bash
git add .
git commit -m "added login page"
git push
```

برای دریافت تغییرات:
```bash
git pull
```
