## 🚀 درباره نیوشاپ

نیوشاپ یک پلتفرم فروشگاهی مدرن با طراحی خیره‌کننده و امکانات پیشرفته است که تجربه‌ای منحصر به فرد برای کاربران ایرانی فراهم می‌کند.

### ✨ ویژگی‌های کلیدی
- 🎨 **طراحی مدرن**: استفاده از Glassmorphism و افکت‌های نئونی
- 🌙 **Dark Mode**: پشتیبانی کامل از حالت شب
- 📱 **Responsive**: بهینه برای تمام دستگاه‌ها
- 🇮🇷 **فارسی**: تایپوگرافی حرفه‌ای با فونت وزیر
- ⚡ **انیمیشن**: افکت‌های سینمایی با GSAP
- 🎯 **3D Product**: نمایش سه‌بعدی محصولات با Three.js

### 📁 ساختار پروژه
```
/workspace
├── shop/          # صفحات فروشگاه
├── admin/         # پنل مدیریت
├── user-panel/    # پنل کاربری
├── auth/          # صفحات احراز هویت
└── assets/        # منابع (CSS, JS, Images, Models)
```

### 🛠️ تکنولوژی‌ها
- HTML5 & CSS3
- Vanilla JavaScript
- Three.js (رندرینگ 3D)
- GSAP (انیمیشن)
- Font: Vazir
